# Art-Deco Gold: редизайн сайта + настоящие слот-символы (гравюра)

## Context
Сайт cv-belatra работает и опубликован. Пользователь выбрал концепт **«Art-Deco Gold»** из четырёх превью и просит превратить слот из эмодзи-версии в настоящую слот-подачу: 8 авторских векторных символов в стиле **золотой гравюры по слоновой кости** (монохром). Игровая логика, стейт-машина, данные и разделы не меняются — меняется визуальный слой и отрисовка символов.

## 1. Дизайн-система Art-Deco
- **`src/styles/tokens.css`** — палитра: фон `#0d0a07`/`#16110a`, золото `#d4af37`/`#f1d27a`/`#8f6b1d` (вертикальный gold-grad), кость `#f7f1df`/`#ecdfbe`, текст `#f5efe0`/`#b7a87f`/`#9a8c6f`, линии `rgba(212,175,55,.35)`. Радиусы меньше (3–6px, прямые линии ар-деко). Убрать бирюзу/розовый — только золото+кость+чёрный.
- **`base.css`** — фон с золотым радиальным свечением сверху; `section-title` ivory→gold; орнаментальный разделитель секций `— ◆ —`.
- **`ui.css`** — кнопки прямоугольные (radius 3px): gold solid / gold outline; чипы, табы (нижняя золотая черта), модалка с двойной золотой рамкой, слайдер/свитч в золоте.

## 2. Навигация и Hero (перестройка)
- **`Navbar.tsx` + `sections.css`** — логотип «G·D·S», ссылки letter-spacing + ромбы-разделители.
- **`Hero.tsx`** — центрированная композиция из превью: kicker `— ✦ ... ✦ —`, заголовок, имя, ряд «арочный автомат | текст + CTA + stats», угловые орнаменты рамки.
- **`MiniSlot.tsx`** — арочный шкаф (radius 120px сверху), костяные ячейки, золотая SPIN-кнопка.

## 3. Слот-машина и бонус
- **`slot.css` + `SlotLab.tsx`/`PrizeParade.tsx`** — корпус с арочным верхом и двойной золотой рамкой; ячейки — слоновая кость с внутренней тенью (единый фон для всех символов); marquee «NEON CARNIVAL» с ромбо-лампами; WIN-баннер — золотая плашка с уголками. Павильоны Prize Parade: римские цифры I/II/III + гравюрные иконки, всё в золоте.

## 4. Символы — золотая гравюра (ключевая часть)
- **Новый `src/components/slotlab/SymbolArt.tsx`**: `<SymbolArt id size>` — 8 ручных SVG (viewBox 64×64, штрих ~2px, тона золота `#5f470f/#8a681c/#c9a548` на кости): шатёр с флагом, билет с перфорацией, звезда с лентой WILD, гранёный алмаз, карусель, театральная маска, шары, мишень со стрелой. Премиальные символы получают дополнительный орнамент-розетку в углах. Плюс 3 иконки павильонов (фейерверк, билеты, звёзды).
- **Замена эмодзи везде**: `Reel.tsx` (ячейки), `MiniSlot.tsx` (hero), легенда символов в `SlotLab.tsx`, GDD-таблица Symbols (новый block kind `symbols-table` в `gdd.ts` + рендер в `GddSection.tsx`), `PrizeParade.tsx`. `data/symbols.ts` остаётся источником имён/описаний/выплат; эмодзи-поле удаляется из рендера.
- Win-анимация: ячейка-кость + золотое свечение рамки, гравюра становится ярче.

1. `npm run typecheck` → `npm run build` — без ошибок.
2. `npx gh-pages -d dist`, дождаться CDN (~2 мин).
3. Браузер: скриншоты desktop (hero, Slot Lab) и mobile 390px; спин; полный бонус по `?demo=bonus`; проверка легенды и GDD-таблицы символов.
4. Коммиты: `feat: art-deco gold design system + hero restructure`, затем `feat: engraved gold SVG slot symbols`; push после каждого.

Не трогаем: `game/` (движок, reducer, paylines), `data/profile|skills|projects|tuning`, Framer Motion анимации, деплой-механику.
